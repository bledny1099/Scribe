GitHub Releases Security Policy

Report an Issue or Vulnerability

Submit bug reports, feature requests, or confidential security disclosures directly to the Scribe team.

🔒 Confidential Security Disclosure:

Security vulnerabilities are submitted directly via GitHub Private Advisories to keep disclosures confidential until a patch is released.

Version Supported
v2.4.2 ✅ Supported
< v2.4.2 🚫 Unsupported
100% Local Privacy
Scribe runs offline on Apple Silicon Neural Engine. No speech or audio is ever transmitted across the network.
Fast Response
Security reports are acknowledged within 24–48 hours. Confirmed bugs are prioritized for the next patch release.
