macOS 14+ (Sonoma, Sequoia) · Apple Silicon & Intel

On-device

Runs entirely on Apple Neural Engine & local WhisperKit. Zero cloud latency.

One shortcut

Press ⌥S to start, press to stop. Rebind it to any key you like.

Pastes anywhere

Text lands in whatever field you were in, Cursor to Telegram, terminal to browser.

Private by default

No account, no API key, no telemetry. Audio never leaves your Mac.

Context-aware

Dynamically primes vocabulary for IDEs, coding agents, notes, chat, and crypto apps.

Works offline

No network connection required. Dictate on a plane or train with zero signal.

Why we built Scribe

We dictate all day

Mostly for prompting coding agents, vibe coding in Cursor & Xcode, drafting documents, and sending quick chat replies. Nothing out there was fast, private, and contextual enough, so we built Scribe and open sourced it.
